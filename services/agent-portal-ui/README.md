# پرتال نماینده بیمه (Agent Portal UI)

پرتال نمایندگان بیمه برای مدیریت بیمه‌نامه‌ها، پیگیری کمیسیون‌ها و صدور بیمه‌نامه جدید.

## قابلیت‌ها

- **صفحه ورود**: احراز هویت نمایندگان
- **داشبورد**: نمایش آمار و فعالیت‌های اخیر
- **مدیریت بیمه‌نامه‌ها**: لیست بیمه‌نامه‌های صادر شده
- **پیگیری کمیسیون‌ها**: وضعیت و مبلغ کمیسیون‌های قابل پرداخت

## نصب و اجرا

```bash
npm install
npm run dev
```

سرویس در پورت 3000 اجرا می‌شود.

## ساختار پروژه

- `src/pages/index.tsx`: صفحه اصلی با تمام صفحات (ورود، داشبورد، بیمه‌نامه‌ها، کمیسیون‌ها)
- `src/pages/_app.tsx`: تنظیمات Next.js
- `src/pages/_document.tsx`: تنظیمات HTML
- `src/styles/globals.css`: استایل‌های جهانی

## متغیرهای محیطی

- `NEXT_PUBLIC_API_URL`: آدرس API سرویس‌ها (پیش‌فرض: http://localhost:3001)

## فناوری‌ها

- Next.js 14
- React 18
- TailwindCSS
- Lucide React (آیکون‌ها)
